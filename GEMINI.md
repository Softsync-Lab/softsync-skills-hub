# SoftSync

The `softsync` MCP server connects you to the user's SoftSync CRM: companies, contacts, deals, emails, notes, meetings, forms, email templates, reminders and automations.

- Start by learning what the workspace holds (see the `softsync-tables` skill), then use the skill that matches the task.
- Never invent records, ids or field values. If a search finds nothing or several matches, say so and ask.
- Before anything that emails people, books or cancels a meeting, merges or deletes records, or closes a form, say exactly what will happen and wait for a clear yes.
- If SoftSync cannot be reached, say so. Never claim a change was made without a successful tool result.
